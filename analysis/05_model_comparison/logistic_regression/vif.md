# 현재 8개 점수지표의 다중공선성(VIF) 분석 결과

작성일: 2026-09-23

현재 사용 중인 **8개 점수지표의 입력값에 대한 VIF는 모두 1.00~1.54로, 심한 다중공선성은 확인되지 않았다.** VIF를 이유로 제외해야 할 지표는 없다.

## 1. 분석 대상과 계산 기준

- 분석 기간: 2010-06-01~2011-05-17
- 분석 단위: 사용자·일
- 분석 규모: 975명, 225,281 사용자·일
- 대상 조건: 개인 기준선 준비 조건을 충족한 `is_scored=1`인 행
- 계산 방법: 8개 설명변수를 함께 고려하고, 각 변수를 나머지 7개 변수로 설명하는 절편 포함 보조회귀의 결정계수로 `VIF = 1 / (1 − R²)` 계산

**이번 결과는 지표별 0~3점으로 변환된 점수 자체의 VIF가 아니라, 점수 산출에 사용하는 입력값의 VIF다.**

| 입력 형태 | 해당 지표 |
| --- | --- |
| 개인 기준선 대비 부호 있는 z값 | 회사계정 외부 발송, 신규 외부 수신자, 회사계정 외부 첨부, 개인계정 첨부, 다른 PC 로그온, 야간 로그온 |
| 0/1 발생 여부 | 구직 키워드 메일, 새로운 야간 메일 |

새로운 야간 메일은 `night_mail_flag=1`이면서 `night_mail_past30=0`인 경우다. 건수형 z는 음수를 0으로 자르지 않은 저장값을 사용했다. VIF 계산에는 사건 정답(y)을 사용하지 않는다.

## 3. 결과 해석

VIF는 한 설명변수가 나머지 설명변수들과 선형적으로 얼마나 겹치는지 확인하는 지표다. 1에 가까울수록 선형 중복이 작다. 일반적으로 **5 이상이면 공선성을 검토**하는 참고 기준을 사용하지만, 절대적인 자동 삭제 기준은 아니다.

현재 최대 VIF는 회사계정 외부 발송의 **1.539**다. 따라서 다음과 같이 판단한다.

1. **현재 8개 지표의 회귀 입력값에서 심한 다중공선성은 확인되지 않았다.**
2. **VIF를 이유로 제외할 지표는 없다.** 8개를 함께 넣는 회귀분석을 진행할 수 있는 수준이다.
3. 외부 발송과 외부 첨부는 일부 관련성이 있지만, 이번 입력값과 표본에서는 둘을 함께 회귀에 넣지 못할 정도의 공선성은 아니다.

## 4. 해석 범위와 주의점

- 낮은 VIF가 각 지표의 탐지 성능이나 통계적 유의성을 증명하지는 않는다.
- **점수 합산 시 행동이 중복 반영되는 문제는 VIF와 별개다.** 외부 첨부가 외부 발송의 부분집합이라는 구조적 관계와 기존 최댓값 반영 정책은 따로 판단해야 한다.
- 이번 수치를 실제 0~3점 지표 점수끼리 계산한 VIF로 표현하면 안 된다. 점수 변환 후의 다중공선성을 확인하려면 해당 점수 컬럼으로 별도 계산해야 한다.
- 기간이나 입력 변환 방식을 바꾸면 VIF도 달라질 수 있다.

**최종 판단: 현재 8개 지표는 점수 산출 입력값 기준으로 다중공선성 문제가 크지 않으며, VIF를 근거로 지표를 삭제할 필요는 없다.**
