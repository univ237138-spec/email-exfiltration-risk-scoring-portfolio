# 사용자·일 사건기간 관련성 분석

- 주 분석: 2010-06-01 이후 is_scored=1인 모든 관측 사용자·일. 경보 여부로 표본을 선별하지 않는다.
- y: CERT r4.2 정답자의 start~end 날짜(양 끝 포함) 안이면 1, 나머지는 0. 실제 악성 이벤트 여부가 아닌 사건기간 대리 라벨이다.
- X: 현재 건수형 6개 지표의 저장된 부호 있는 개인 기준선 z, 구직 키워드 플래그, 새로운 야간 메일 플래그. 기존 정수 점수·총점·IF 출력·정답 사용자 ID는 설명변수에 넣지 않는다.
- Pearson/Spearman과 절편을 포함한 설계행렬의 VIF를 계산한다. VIF만으로 자동 삭제하지 않는다.
- 무벌점 이항 로지스틱 최대우도 추정. 사용자별 score 합에 기반한 CR1 sandwich 표준오차, 사용자 수-1 자유도의 t 기준 p와 95% CI. 주 분석 8개 검정에 BH q값도 참고로 제시한다.
- 부호 있는 z 1단위 증가, 플래그 0→1에 대한 조정 OR를 제시한다. pseudo-R²는 working-independence likelihood의 McFadden 지표이며 분산 설명률이 아니다.
- 민감도: IF와 같은 z 양수 절단, 구직 키워드 제외, 시나리오 2 사용자 전체 제외(지원이 없는 변수는 별도 표시), 월 고정효과 추가, z=0에서 기울기가 달라지는 모형. 모형별 결과가 달라지면 보고한다.
- 검증: 사용자·일 중복/유한값/라벨 일치, 수렴/정보행렬/score, 독립 라이브러리 sklearn 무벌점 회귀와 계수 비교, VIF 독립 계산, sandwich 사용자 합 독립 계산.
- 사후 탐색 분석이다. 현재 데이터는 독립 홀드아웃이 아니며 이번 회귀의 학습 내 적합도를 새 탐지 성능으로 주장하지 않는다. 기존 점수 정책과 IF 모델은 변경하지 않는다.
