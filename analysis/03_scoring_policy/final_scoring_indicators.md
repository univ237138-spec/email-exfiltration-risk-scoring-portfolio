## 1. 점수지표 8개

| # | 채널 | 구분 | 지표 (컬럼) | 점수 방식 | 1 / 2 / 3점 경계 (z) | 점수 |
|---|---|---|---|---|---|---|

| 3 | 이메일 | 핵심 | 회사 계정 외부 첨부 (`corp_ext_att_mail_cnt`) | 개인 기준선 z | 1.64 / 1.90 / 2.79 | 0~3 |

- **개인 기준선 z** = (오늘 값 − 직전 30활동일 평균) ÷ max(표준편차, 1)
- **z 경계:** 보정기간(2010-01~05) 상위 1% / 0.25% / 0.05% 지점. 정답 미사용.
- 지표가 4개로 줄었지만 주의 등급 경보율 기준으로 경계를 재계산하지 않기로 했습니다([점수구간_보정_기준.md](score_boundary_calibration.md) 3절).

## 2. 점수 계산과 등급

| 구분 | 이메일 | 로그온 |
|---|---|---|
| 점수 | 지표 1~6을 사용하되, 지표 1·3은 **큰 점수 하나만** 반영하고 나머지를 합산 | 지표 7·8 중 **큰 값** (0~3). 동점이면 값 하나만 사용 |
| 관심 | 2점 | 1점, 또는 2점이면서 로그온 z < 1.94 |
| **주의** | **3~4점** | **2점이면서 로그온 z(두 지표 중 큰 값) ≥ 1.94** |
| **위험** | **5점 이상** | **3점** |
| 경보 | 주의 이상 | 주의 이상 |
| 경보 사유 | 점수가 가장 큰 이메일 지표 | 점수가 높은 쪽 지표. **동점이면 두 지표 모두 + "동시 발생"** |

- **조사 대상** = 이메일 주의 이상 **또는** 로그온 주의 이상. 두 점수는 더하지 않고, 경보 채널(이메일 / 로그온 / 둘 다)로 구분해 표시합니다.
- 회사 계정 외부 발송과 회사 계정 외부 첨부는 둘 다 점수지표입니다. 각각 z와 0~3점은 계산·표시하되, 외부 첨부가 외부 발송의 부분집합이므로 이메일 총점에는 `max(외부 발송 점수, 외부 첨부 점수)`만 반영합니다. 동점이어도 한 번만 반영합니다.
- 로그온 z 경계 1.94는 보정기간만으로 정했습니다(`로그온_별도경보_설계.md` "결정").
- **직무 보정: 없음 (2026-09-22 확정, 추후 재검토 가능).** 모든 직무에 같은 개인 기준선 z와 공통 경계를 씁니다. IT 관리자(ITAdmin 39명)가 로그온 경보의 89.2%를 차지하는 점은 알려진 한계입니다. 직무 보정 강도 비교는 [20260922_직무보정_분할검증/결과.md](../06_rejected_alternatives/role_adjustment_split/report.md) 참고.
